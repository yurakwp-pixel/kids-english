# kids-english M0–M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 아이가 영어로 말하면 놀이판(멍멍이 + 아기 공룡)이 바로 반응하고, 캐릭터가 영어로 짧게 답하는 로컬 웹앱의 뼈대(M0), 걷는 뼈대(M1), 말로 짓기(M2)를 만든다.

**Architecture:** 브라우저(순수 ES 모듈)가 Web Speech로 들은 n-best를 `POST /api/turn`으로 보내면, Python 표준 라이브러리 서버가 NDJSON 두 줄로 답한다. 1줄은 즉시 반응(fastpath 또는 ack), 2줄은 LLM 답이다. LLM은 `claude-agent-sdk`의 `ClaudeSDKClient` 하나를 전용 asyncio 스레드에서 세션 동안 살려 두고, 사용자 설정과 도구를 모두 격리한 채 haiku로 호출한다. 놀이판에 그릴 수 있는 것(`shared/catalog.json`)과 배울 단어(`content/words/*.json`)는 데이터 파일이고, Python 검증기와 JS 렌더러가 같은 카탈로그를 읽는다.

**Tech Stack:** Python 3.13 (stdlib `http.server`, `asyncio`, `threading`), `claude-agent-sdk==0.2.172`, pytest, jsonschema, 브라우저 Web Speech API, speechSynthesis, 인라인 SVG, `node --test`(Node 24).

**Spec:** `docs/superpowers/specs/2026-10-22-kids-english-design.md` (승인됨). 벤치마크: `docs/benchmark/aleph-kids.html`, `docs/benchmark/shunibini.md`.

모든 경로는 프로젝트 루트 `kids-english/` 기준이다. 명령은 Git Bash에서 이 폴더를 cwd로 실행한다. 경로에 한글과 공백이 있으니 따옴표를 빼지 않는다.

## Global Constraints

- Python 가상환경은 `.venv`. 런타임 의존성은 정확히 `claude-agent-sdk==0.2.172` 하나, 개발 의존성은 `pytest`, `jsonschema`.
- 프론트엔드는 프레임워크와 빌드 없이 순수 ES 모듈. DOM이 없는 모듈만 `node --test`로 테스트.
- 서버는 `127.0.0.1:8771`에만 바인딩.
- 아이 화면은 외부 리소스(CDN, 웹폰트, 이미지 URL)를 불러오지 않는다. 개발 문서 뷰어 `docs/index.html`만 CDN 허용.
- 아이 UX: 누르는 것 최소 120px(마이크 버튼 지름 최소 160px), 글씨 최소 28px, `pointer` 이벤트, 키보드 조작 없음, 1초에 3번 넘는 깜빡임 금지, 게임오버·감점 없음, "Wrong"/"No" 같은 부정 표현 금지.
- 멍멍이의 `chomp` 동작은 음식(`food:true`) 물건만 대상으로 한다. 사람이나 캐릭터를 무는 장면은 없다.
- `say`는 15단어 이하, 한글 금지, `<` 금지, URL 금지. 한글은 `korean_hint`에만. 한 턴의 `ops`는 최대 4개.
- 한글이 들어간 입력의 답에는 `ops`가 비어 있어야 한다(서버가 강제).
- 지연 목표(음성인식 최종 결과 시점부터): ack 0.1초, fastpath 0.5초, LLM p50 2.5초 / p95 4초, 8초에 대체 대사.
- 저장은 텍스트만 `data/`(gitignore). 오디오는 저장하지 않는다. `.env`도 gitignore.
- 자격증명 값은 코드, 로그, 커밋, 채팅에 쓰지 않는다. `CLAUDE_CODE_OAUTH_TOKEN`은 사용자가 직접 `.env`에 넣는다.
- 멍멍이는 공식 그림을 쓰지 않고 직접 그린 SVG만 쓴다. 화면 속 영어 이름은 "Chomp".
- 커밋 메시지는 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`로 끝낸다.

3. **빈 인식 결과나 잡음:** `alternatives: []`이거나 "uh", "um"만 들어오면 LLM을 부르지 않고 "Say it again!" 류 템플릿으로 답한다. → Task 6.

5. **과한 요청:** "ten eggs", "big big big egg", 장면에 물건 30개가 쌓이는 상황 → 개수는 5로 자르고, `ops`는 4개 이하, 장면 물건은 최대 20개(가장 오래된 것부터 제거). → Task 11, Task 14.

def test_fake_llm_replays_script_and_records_calls():
    llm = FakeLLM(script=['{"say":"Hi!"}', '{"say":"Bye!"}'])
    llm.start_session("SYS")
    assert [llm.complete("a", 8).text, llm.complete("b", 8).text, llm.complete("c", 8).text] == ['{"say":"Hi!"}', '{"say":"Bye!"}', '{"say":"Bye!"}']
    assert llm.system_prompt == "SYS" and llm.calls == ["a", "b", "c"]

def test_praise_cycles():

### Task 11: fastpath

**Files:**
- Create: `server/fastpath.py`, `server/ids.py`
- Test: `tests/py/test_fastpath.py`

**Interfaces:**
- Consumes: Task 9 `Catalog`, Task 10 `WordBank`/`Word`, Task 6 `normalize`, Task 3 `praise`
- Produces:
  - `@dataclass(frozen=True) class FastMatch: ops: list[dict]; say: str; grade: Literal["exact","partial"]; word_ids: list[str]`
  - `match(alternatives: Sequence[str], bank: WordBank, catalog: Catalog, scene: Sequence[dict], *, turn_id: int, level: int = 2) -> FastMatch | None`
- 규칙(테스트가 고정하는 것):
  1. 후보를 순서대로 보고 처음 맞는 것을 쓴다. 한글이 들어간 후보는 건너뛴다.
  2. 앞의 호칭(`chomp`, `dino`, `hey chomp`)은 떼어 내고 그 캐릭터를 우선 행위자로 쓴다. 그 캐릭터가 할 수 없는 동작이면 호칭은 무시한다.
  3. 물건 문법 `[숫자]? [크기]? [색]? 물건`. 개수는 `max_count`(5)로 자르고, 색이나 크기를 못 가지는 물건이면 그 속성은 버린다. `add` op에 `place`는 넣지 않는다(레이아웃이 정한다).
     - **id 규칙:** `add` op에는 서버가 정한 id를 넣는다. count가 1이면 `"id"`, 2 이상이면 `"ids"` 목록이다.
     - id 형식은 `"{kind}{n}"`이고, n은 장면과 같은 답 안에 이미 있는 그 kind의 가장 큰 번호 + 1이다.
     - 이 규칙은 `server/ids.py`의 `next_ids(kind: str, count: int, scene: Sequence[dict], pending: Sequence[dict]) -> list[str]` 하나로 구현하고, Task 12도 이 함수를 쓴다.
  4. 동작 문장: `accept`의 `{object}`는 위 물건 문법 하나로 채울 수 있다.
     - `needs` 물건이 장면에 없으면 `add`를 앞에 붙인다.
     - `removes`면 해당 물건들을 `remove`한다.
     - `act` op의 `target`은 장면의 그 물건 id다.
  5. `chomp` 동작의 대상이 음식이 아니면 매치하지 않는다(→ LLM이 다른 걸 제안).
  6. `grade`: 맞은 패턴이 `accept[0]`(정규 문장)이면 `exact`, 다른 변형이면 `partial`. 물건 문법만으로 맞으면 `exact`.
  7. `say`: `exact`이면 `"{praise(turn_id)} {En}!"`, 물건이면 `"{praise} A big red egg!"`처럼 바른 영어. `partial`의 `say`는 임시값이다(오케스트레이터가 LLM 답으로 바꾼다).
  8. `ops` 총 개수가 `max_ops`(4)를 넘으면 뒤를 자른다.
